# Identidad del portal

Decisión del piloto: conservar el nombre inicial «Scanner Portal — Piloto» y evolucionar hacia una experiencia propia de Kaz Demos.

- Marca visible prevista: **Powered by Kaz Demos** en pie o área de identidad del componente SPFx.
- Logo aprobado por el usuario: [`labs/MipSdkAudit/kaz-demos-entra-215.png`](../../labs/MipSdkAudit/kaz-demos-entra-215.png).
- Mantener encabezado y controles nativos de SharePoint. La marca no debe sugerir que el portal es un producto oficial de Microsoft.
- Al implementar SPFx: texto alternativo «Kaz Demos», dimensiones adaptables, contraste y pruebas con teclado/zoom. Conservar el recurso local al paquete, sin depender de una URL `blob` de GitHub en producción.

La creación inicial de sitio vacío no aplica aún un tema ni instala el componente visual. El branding forma parte de SP4 y se probará sobre el sitio piloto.
